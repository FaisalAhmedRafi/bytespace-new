# ByteSpace New

An online course marketplace UI built with Next.js, TypeScript and Tailwind CSS.

**Live demo:** https://bytespace-new-ruby.vercel.app

## Pages
- `/` Landing page (hero, course browser, learning paths, testimonials)
- `/login` Login page
- `/register` Register page

## Tech Stack
- Next.js 15 (App Router)
- React 19
- TypeScript
- Tailwind CSS

## Getting Started
npm install
npm run dev

Open http://localhost:3000.

## Project Structure
- `app/` routes and layouts
- `components/` reusable UI components
- `lib/data.ts` demo data

## Notes
Auth form submit handlers are stubs, to be connected to a backend.
